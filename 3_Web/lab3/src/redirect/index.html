Лабораторная работа №3

Это страница-переход к лабораторной работе №3 по веб-программированию. На Helios приложение разворачивается в WildFly: сервер принимает HTTP-запросы, обрабатывает сервлеты и отдаёт страницы JSP.

Порты Helios закрыты снаружи, поэтому лабораторная открывается через SSH-туннель. Скопируйте команду, замените sXXXXXX на ваш ИСУ и выполните её в терминале:

ssh -p 2222 -L 20716:localhost:20716 sXXXXXX@helios.cs.ifmo.ru

Сайт localhost:20716/lab3 будет работать только пока открыт терминал, в котором вы ввели команду. Чтобы остановить туннель, закройте терминал или нажмите Ctrl+C.
