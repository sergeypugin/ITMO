Лабораторная работа №2

Это страница-переход к лабораторной работе №2 по веб-программированию. На Helios запускается личный экземпляр Apache httpd: он отдаёт статику, а Java FastCGI-сервер обрабатывает AJAX-запросы.

Порты Helios закрыты снаружи, поэтому лабораторная открывается через SSH-туннель. Скопируйте команду, замените xxxxxx на ваш ИСУ и выполните её в терминале:

ssh -p 2222 -L 10714:localhost:10714 sXXXXXX@helios.cs.ifmo.ru

Сайт localhost:10714 будет работать только пока открыт терминал, в котором вы ввели команду. Чтобы остановить туннель, закройте терминал или нажмите Ctrl+C.
