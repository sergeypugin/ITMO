## Письменная часть

#### Задание 1. Правила создания HTML-форм.

- Форма задаётся тегом `<form>`. Вложенные формы **запрещены**.
- Одновременно на сервер может отправляться **только одна** форма.
- Атрибут `action` задаёт URL-адрес обработчика на сервере.
- Атрибут `method` определяет HTTP-метод передачи данных (`GET` по умолчанию или `POST`).
- Для передачи файлов требуется атрибут `enctype="multipart/form-data"`.
- Каждое поле ввода обязано иметь атрибут `name`, иначе его значение не передаётся серверу.
- Для отправки формы используется кнопка с `type="submit"`.
- Текстовая метка связывается с полем через `<label for="id_поля">` и атрибут `id` у поля ввода.

#### Задание 2. HTML-страница, отображающая список товаров для маркетплейса Oson. Должна быть строка поиска. На карточке товара должно быть изображение (статическая ссылка на внешний ресурс), название товара, цена и кнопка "добавить в корзину".

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Oson -- Каталог</title>
</head>
<body>

    <!-- Строка поиска -->
    <header>
        <form action="/search" method="GET">
            <input type="search" name="query" placeholder="Поиск товаров...">
            <button type="submit">Найти</button>
        </form>
    </header>

    <!-- Список товаров -->
    <main>
        <section>
            <!-- Карточка 1 -->
            <article>
                <img src="https://via.placeholder.com/150" alt="Ноутбук Oson">
                <h3>Ноутбук Oson Pro</h3>
                <p>Цена: 59 990 руб.</p>
                <button type="button">Добавить в корзину</button>
            </article>

            <!-- Карточка 2 -->
            <article>
                <img src="https://via.placeholder.com/150" alt="Мышь беспроводная">
                <h3>Мышь беспроводная Oson</h3>
                <p>Цена: 1 490 руб.</p>
                <button type="button">Добавить в корзину</button>
            </article>
        </section>
    </main>

</body>
</html>
```
