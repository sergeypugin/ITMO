#### Вопрос 2. Выберите корректные утверждения о принципе AJAX

- [ ] AJAX позволяет выполнить синхронное обращение к серверу, чтобы дождаться ответа сервера и только потом продолжить выполнение обработчика
- [x] AJAX позволяет выполнить асинхронное обращение к серверу, чтобы не блокировать обработку событий и действий пользователя, пока данные грузятся с сервера
- [ ] AJAX позволяет клиенту узнать о событии, произошедшем на сервере, посредством опроса с коротким интервалом. Работает в любых инфраструктурных средах
- [ ] AJAX позволяет динамически изменять структуру HTML при помощи DOM без обращения к серверу

#### Вопрос 3. Выберите корректные утверждения о принципе FastCGI

- [ ] Согласно данному принципу веб-сервер запускает обработчик запроса клиента на языке Java, реализованный в виде сервлета
- [x] Согласно данному принципу веб-сервер запускает пул процессов-обработчиков и делегирует обработку входящих запросов данным обработчикам, обмениваясь с ними данными по TCP или Unix Domain сокетам
- [x] С использованием данного принципа серверные сценарии могут быть написаны на любом языке программирования
- [ ] Согласно данному принципу веб-сервер запускает отдельный процесс на каждый приходящий запрос, обмениваясь данными с процессом по stdin и stdout

#### Вопрос 4. О каком принципе идет речь?

Преимущество данного принципа в том, что отсутствуют конфликты параллельной обработки данных, серверный сценарий можно написать на любом языке программирования, и при этом веб-приложения, реализованные на основе данного принципа, могут быть эффективно масштабированы на дополнительные серверные мощности. Благодаря этому преимуществу данный принцип получил большое распространение в веб-программировании и используется в таких веб-серверах как Nginx и Python uWSGI.
