```css
  /* стили */
}
```

#### Вопрос 5. Напишите разметку (опционально, CSS стили). Таблица котиков. 3 столбца: кличка, возраст и порода. Минимум 3 строки с данными о котиках внутри таблицы. Внутри ячеек таблицы должен быть внутренний отступ в 16px вокруг текста от границ ячеек. Граница должна быть черной, непрерывной, толщиной в 1 пиксель.

```html
<table>
  <tr>
    <th>Кличка</th>
    <th>Возраст</th>
    <th>Порода</th>
  </tr>
  <tr>
    <td>Барсик</td>
    <td>3 года</td>
    <td>Британец</td>
  </tr>
  <tr>
    <td>Мурзик</td>
    <td>2 года</td>
    <td>Сиамская</td>
  </tr>
  <tr>
    <td>Васька</td>
    <td>5 лет</td>
    <td>Мейн-кун</td>
  </tr>
</table>

<style>
  table {
    border-collapse: collapse;
  }
  th, td {
    border: 1px solid black;
    padding: 16px;
  }
</style>
```
