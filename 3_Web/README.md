Код всех работ представлен в папках `labX`, куда также добавлены текст заданий (`LMS.md`) и расписанная до неплохого минимума теория (`questions.md`).

> [!note]
> Для сохранения единого оформления между лабораторными работами (ЛР2, ЛР3, ЛР4) используемые стили, картинки и прочее вынесено в `3_Web/common/`.
>
> На Helios эта папка живёт в `~/public_html/web/common/` и используется страницей-перехода и личным Apache через `htdocs/common`, символическую ссылку на неё. Папка заливается отдельно командой `scp -r 3_Web/common/. helios:public_html/web/common/` и в `src/build/` не попадает
>
> Шрифт -- Nunito, скачать можно на [Google Fonts](https://fonts.google.com/specimen/Nunito). В `common/assets/fonts/` лежат только используемые подмножества -- латиница и кириллица
