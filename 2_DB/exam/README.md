## Вресия 26-го года

**Экзамен по Базам данных**

1. На основании предметной области из варианта: А) Построить даталогическую модель (минимум 6 сущностей, требуется реализация связи многие-ко-многим). Все полученные отношения должны соответствовать 3НФ, хотя бы одна из сущностей должна содержать не менее 4 атрибутов. Целевая СУБД: PostgreSQL 15. B) Указать, между какими сущностями реализована связь многие-ко-многим. C) Для сущностей с 4 атрибутами доказать, что они в 3НФ.
    
2. Потока была два, но отличался только этот пункт:
	1. Предложите триггеры для построенной модели, опишите их назначение и основные параметры (тип, когда должен срабатывать), которые нужны для их реализации.
	2. Предложите представления для построенной модели, опишите их назначение и укажите вид.

3. На основе даталогической модели из п.1 придумайте и напишите SQL-запрос, который использует сущности, соединенные связью многие-ко-многим через необходимые соединения (INNER JOIN).
    
4. Для запроса из п.3: А) Изобразите эффективный план выполнения запроса (можно добавить индексы). B) Для использованных соединений (INNER JOIN) укажите алгоритм. Поясните, почему был выбран именно такой план для запроса и алгоритм для СУБД.

На рубеже было 6 сущностей, мэни-ту-мэни и 5 сущностей в одной, тут же сократили до 4-х. Приятный бонус - можно триггеры и не писать, а только описывать, однако НФ придётся вспомнить.
