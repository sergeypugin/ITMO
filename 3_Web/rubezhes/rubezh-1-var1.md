## Письменная часть

#### Задание 1. Методы HTTP. Описать хотя бы 5 методов, их назначение и особенности применения.

> Более подробно с методами HTTP можно ознакомиться [тут](../lab1/questions.md#методы-http)

- **GET** -- получение ресурса. Безопасный (не изменяет состояние сервера) и идемпотентный. Параметры передаются в query string, ответ можно кэшировать.
- **POST** -- создание ресурса или передача данных для обработки. Не идемпотентный: повторный запрос может создать дубликат. Данные передаются в теле запроса.
- **PUT** -- создание или полная замена ресурса по известному URI. Идемпотентный: повторный вызов не меняет результат.
- **DELETE** -- удаление ресурса по указанному URI. Идемпотентный.
- **HEAD** -- аналогичен GET, но сервер возвращает только заголовки без тела ответа. Используется для проверки существования ресурса и его метаданных.
- **OPTIONS** -- перечисляет методы, поддерживаемые ресурсом. Применяется в CORS preflight-запросах.
- **PATCH** -- частичное изменение ресурса, в отличие от PUT, который заменяет его целиком.

#### Задание 2. JavaScript-функция, заменяющая все текстовые ссылки на странице, оформленные при помощи тега `<a>`, на кнопки с тем же текстом.

```javascript
function replaceLinksWithButtons() {
  const links = document.querySelectorAll('a');
  for (const link of links) {
    const button = document.createElement('button');
    button.textContent = link.textContent;
    link.replaceWith(button);
  }
}
```
